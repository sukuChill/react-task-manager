React Tutorial
============

This is a simple React app created using Vite.

Getting Started
---------------

1. Create a new React app using Vite:

```
npm create vite@4.1.0 react-app
```

2. Navigate to the app directory:

```
cd react-app/
```

3. Install dependencies:

```
npm i
```

4. Start the development server:

```
npm run dev
```

5. Install Bootstrap:

```
npm i bootstrap@5.2.3
```

6. Remove the existing CSS files:

- Delete `app.css`
- Delete `index.css`

7. Import Bootstrap in `main.tsx`:

```javascript
import "bootstrap/dist/css/bootstrap.css";
```

State
-----

- State changes will trigger a re-render of the component

Example:

```javascript
const [selectedIndex, setSelectedIndex] = useState(-1);
```

Props
-----

- Pass data between components using props
- Props are similar to POJO or DTO classes
- Define prop types using interfaces

Example:

```javascript

  children: ReactNode;
```

```import axios from "axios";
import { useState } from "react";

interface PostResponse {
  userId: number;
  id: number;
  title: string;
  body: string;
}

const Posts = () => {
  const [showButton, setShowButton] = useState(true);
  const [posts, setPosts] = useState<PostResponse[]>([]);

  const handleOnClick = async () => {
    setShowButton(false);
    const response = await axios.get(
      "https://jsonplaceholder.typicode.com/posts/"
    );
    setPosts(response.data);
    // console.log(response.data);
  };
  return (
    <>
      {showButton && (
        <button
          type="button"
          className="btn btn-danger"
          onClick={handleOnClick}
        >
          Load Posts
        </button>
      )}
      <ul className="list-group">
        {posts.map((post) => (
          <li className="list-group-item" key={post.id}>
            <div>
              <h2>{post.title}</h2>
              {post.body}
              <br />
              Author: {post.userId}
            </div>
          </li>
        ))}
      </ul>
    </>
  );
};
export default Posts;
```
